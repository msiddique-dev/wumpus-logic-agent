# Wumpus Logic Agent

A web-based Knowledge-Based Agent that navigates the Wumpus World using Propositional Logic and Resolution Refutation.

## Live Demo
[View Live App](https://wumpus-logic-agent.vercel.app)

## Features
- Dynamic grid sizing (3x3 to 7x7)
- Propositional Logic Knowledge Base (KB)
- CNF-based Resolution Refutation inference engine
- Real-time metrics dashboard
- Step-by-step and Auto agent modes

## Tech Stack
HTML5 · Vanilla JavaScript · CSS3
